# Matchmanager Front-end Prototype

A premium-styled Next.js + Tailwind front-end prototype for reviewing the Matchmanager owner dashboard.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Open in browser:
   - http://localhost:3000

## Included dashboard areas

- Matchmanager logo/title and owner dashboard heading
- Player numbers and attendance snapshot
- Trialist pipeline including signed-up and not-signed-up breakdown
- Finance overview for total group + girls, boys, youth
- Task panels for operation manager, subgroup manager, and coach
- Session blocks for Saturday/Sunday and Tuesday/Wednesday sites
